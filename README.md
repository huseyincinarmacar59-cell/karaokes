# 🎤 Cep Mikrofon

Telefonun mikrofonundan aldığı sesi efektsiz, düz şekilde Bluetooth hoparlöre veren basit web uygulaması.

1. Telefonu Bluetooth hoparlöre bağla
2. Sayfayı aç, butona bas, mikrofon izni ver
3. Ses ayarını kaydırıcıdan yap

Ses az geliyorsa "Mikrofon" listesinden iPhone Mikrofonu'nu seç.
Hoparlöre çok yaklaşırsan ses geri dönüp uğultu yapar, biraz mesafe bırak.
